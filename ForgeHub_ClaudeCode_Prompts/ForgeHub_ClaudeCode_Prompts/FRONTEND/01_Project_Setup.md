# Project Setup

## Instructions

Read and follow:

- PRD.md

### Objective

Set up the production-ready Next.js frontend. Read PRD.md, TRD.md, UI_UX.md before coding. Implement architecture, design system, routing, reusable components, Tailwind, TypeScript, Framer Motion, GSAP, Three.js, documentation. Stop after completion.

Requirements:

- Production-quality code
- TypeScript
- Next.js App Router
- Tailwind CSS
- Responsive
- Accessible (WCAG AA)
- Reusable components
- No backend implementation
- Use mock data where needed

When complete:

1. Refactor.
2. Ensure no build errors.
3. Explain what was built.
4. Stop and wait for the next phase.
